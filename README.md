# ระบบแสดงผลและจัดการออกรางวัลสลากกาชาด ประจำปี 2570
### งานเทศกาลปีใหม่สี่เผ่าไทย จังหวัดศรีสะเกษ (Sisaket Red Cross Lottery System 2570)

ระบบเว็บแอปพลิเคชันสำหรับแสดงผลการออกรางวัลสลากกาชาดบนหน้าจอโปรเจกเตอร์/เวทีกลาง และระบบจัดการสำหรับเจ้าหน้าที่ (Admin Only) พัฒนาด้วย **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS** และพร้อมเชื่อมต่อ **MongoDB**

---

## 🌟 จุดเด่นและคุณสมบัติของระบบ

1. **หน้าจอแสดงผลสดบนโปรเจกเตอร์ (Projector Presentation Dashboard)**:
   - ออกแบบตรงตามต้นแบบจริงที่ฉายบนเวที (รูปถ่ายอ้างอิง ปี 2570)
   - มี **Auto-Update รีเฟรชข้อมูลทุก 5 วินาที** โดยอัตโนมัติ ไม่ต้องกด F5 หรือรีโหลดหน้าเว็บ
   - เมื่อเจ้าหน้าที่ป้อนหมายเลขใหม่ ตัวเลขจะเด้งขยายพร้อมเอฟเฟกต์ไฟวิ่งสีทอง (`number-pop`) และมีเสียงดนตรีแจ้งเตือน (Chime)
   - มีปุ่มเข้าโหมดเต็มจอ (**Fullscreen Mode**) สำหรับขึ้นจอโปรเจกเตอร์
   - มีหน้าต่าง **ตรวจสลากกาชาด** สำหรับค้นหาหมายเลขสลาก 5 หลัก หรือ 3 หลัก

2. **โครงสร้าง 7 หมวดรางวัล (127 รางวัล)**:
   - **รางวัลที่ 1** (2 รางวัล - 5 หลัก): รถยนต์โตโยต้าฟอร์จูนเนอร์ 2.4 LEADER G Plus
   - **รางวัลที่ 7** (4 รางวัล - 5 หลัก): ทองคำแท่งน้ำหนัก 1 สลึง *(คำนวณข้างเคียงอัตโนมัติจากรางวัลที่ 1)*
   - **รางวัลเลขท้าย 3 ตัว** (100 รางวัล - 3 หลัก): พัดลมตั้งพื้น ขนาด 16 นิ้ว *(ออก 1 หมายเลขท้าย 3 ตัว ถูก 100 รางวัล)*
   - **รางวัลที่ 2** (3 รางวัล - 5 หลัก): ทองคำแท่งน้ำหนัก 1 บาท
   - **รางวัลที่ 3** (3 รางวัล - 5 หลัก): โทรศัพท์เคลื่อนที่ Apple iPhone 18 Pro
   - **รางวัลที่ 4** (5 รางวัล - 5 หลัก): รถจักรยานยนต์ Honda Wave
   - **รางวัลที่ 5** (10 รางวัล - 5 หลัก): ตู้เย็น 2 ประตู ขนาด 7 คิว

3. **ระบบคำนวณรางวัลข้างเคียงอัตโนมัติ (Auto-Adjacent Calculation)**:
   - เมื่อ Admin กรอกรางวัลที่ 1 เช่น `00051` และ `71827`
   - ระบบจะคำนวณและเติมรางวัลข้างเคียงให้ทันที: `00050`, `00052`, `71826`, `71828`
   - แอดมินสามารถคลิกแก้ไขหรือปรับแต่งหมายเลขได้อิสระ

4. **ระบบความปลอดภัยเฉพาะ Admin (Single Admin Role)**:
   - เข้าผ่าน `/admin` หรือกดเมนูบนหน้าหลัก
   - ป้องกันสิทธิ์ด้วยรหัสผ่านและ HTTP-Only Secure Cookie
   - มีฟังก์ชันสลับสถานะ: "กำลังออกรางวัล (Live)", "ออกรางวัลเสร็จสิ้น", "พักการออก"
   - มีปุ่ม "โหลดข้อมูลตัวอย่าง" (ตรงตามรูป) และ "ล้างกระดาน" (สำหรับเริ่มจับรางวัลจริง)

5. **ระบบจัดเก็บข้อมูล (Storage & MongoDB Ready)**:
   - ปัจจุบันทำงานผ่าน Local JSON Storage พร้อมใช้งานทันทีโดยไม่ต้องตั้งค่าฐานข้อมูลล่วงหน้า
   - **เมื่อต้องการเชื่อมต่อ MongoDB**: เพียงใส่ `MONGODB_URI` ใน `.env.local` ระบบจะเชื่อมต่อ MongoDB Atlas หรือ Local Mongo ให้อัตโนมัติทันที

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

### 1. ติดตั้งแพ็กเกจ (Dependencies)
```bash
npm install
```

### 2. รันโหมด Development
```bash
npm run dev
```
เปิดบราวเซอร์ที่: `http://localhost:3000`

- **URL เข้าสู่ระบบ**: `http://localhost:3000/admin`
- **รหัสผ่านเริ่มต้น**: `admin2570`
*(สามารถเปลี่ยนรหัสผ่านได้ในไฟล์ `.env.local` ผ่านตัวแปร `ADMIN_PASSWORD`)*

---

## 🍃 วิธีเชื่อมต่อ MongoDB

เมื่อคุณพร้อมเชื่อมต่อ MongoDB ให้เปิดไฟล์ `.env.local` แล้วใส่ Connection URI:

```env
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/lottery?retryWrites=true&w=majority
ADMIN_PASSWORD=admin2570
ADMIN_SECRET=sisaket2570admin
```

เมื่อใส่แล้ว ให้รีสตาร์ทเซิร์ฟเวอร์ (`npm run dev`) ข้อมูลผลสลากจะถูกบันทึกและอ่านจากคอลเลกชันใน MongoDB ทันที
