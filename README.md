# ระบบแสดงผลและจัดการออกรางวัลสลากกาชาด ประจำปี 2570
### งานเทศกาลปีใหม่สี่เผ่าไทย จังหวัดศรีสะเกษ (Sisaket Red Cross Lottery System 2570)

ระบบเว็บแอปพลิเคชันสำหรับแสดงผลการออกรางวัลสลากกาชาดบนหน้าจอเวที/โปรเจกเตอร์ และระบบจัดการสำหรับเจ้าหน้าที่ (Single Admin) พัฒนาด้วย **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, ออกแบบตามหลักการ **`unslop`** เพื่อความเป็นระเบียบและเป็นทางการ พร้อมเชื่อมต่อฐานข้อมูล **MongoDB Atlas** แบบ Real-time

---

## 🌟 คุณสมบัติและสถาปัตยกรรมของระบบ

1. **หน้าจอแสดงผลสด (Live Projector Dashboard - `unslop` Design)**:
   - ออกแบบเลย์เอาต์ตามลำดับแถวรางวัลชัดเจน: **1st $\rightarrow$ 2nd $\rightarrow$ 3rd $\rightarrow$ 4th $\rightarrow$ 5th $\rightarrow$ 6th (เลขท้าย 3 ตัว) $\rightarrow$ 7th (ข้างเคียง)**
   - **อัปเดตข้อมูลอัตโนมัติทุก 5 วินาที** (Auto-polling every 5 seconds) ไม่ต้องรีโหลดหน้าเว็บ
   - เมื่อเจ้าหน้าที่ป้อนหมายเลขใหม่ ตัวเลขจะได้รับการไฮไลต์สีอำพันทองคำนุ่มนวล พร้อมเสียงแจ้งเตือน (Chime sound)
   - มีปุ่มเข้าโหมดเต็มจอ (**Fullscreen Mode**) สำหรับขึ้นจอโปรเจกเตอร์หรือทีวีในงาน
   - มีปุ่ม **"ตรวจสลาก"** สำหรับค้นหาหมายเลขสลาก 5 หลัก หรือ 3 หลักเพื่อตรวจรางวัล
   - มีปุ่ม **"รายการรางวัล"** สรุปของรางวัลทั้งหมด 127 รายการ

2. **โครงสร้าง 7 หมวดรางวัล (127 รางวัล สลาก 99,999 ฉบับ)**:
   - **Row 1 — รางวัลที่ 1** (2 รางวัล • 5 หลัก): รถยนต์โตโยต้าฟอร์จูนเนอร์ 2.4 LEADER G Plus
   - **Row 2 — รางวัลที่ 2** (3 รางวัล • 5 หลัก): ทองคำแท่งน้ำหนัก 1 บาท
   - **Row 3 — รางวัลที่ 3** (3 รางวัล • 5 หลัก): โทรศัพท์เคลื่อนที่ Apple iPhone 18 Pro
   - **Row 4 — รางวัลที่ 4** (5 รางวัล • 5 หลัก): รถจักรยานยนต์ Honda Wave
   - **Row 5 — รางวัลที่ 5** (10 รางวัล • 5 หลัก): ตู้เย็น 2 ประตู ขนาด 7 คิว
   - **Row 6 — รางวัลเลขท้าย 3 ตัว** (100 รางวัล • 3 หลัก): พัดลมตั้งพื้น ขนาด 16 นิ้ว *(ออก 1 หมายเลขท้าย 3 ตัว ถูก 100 รางวัล)*
   - **Row 7 — รางวัลข้างเคียงรางวัลที่ 1** (4 รางวัล • 5 หลัก): ทองคำแท่งน้ำหนัก 1 สลึง *(ระบบคำนวณ $\pm 1$ จากรางวัลที่ 1 ทั้ง 2 รางวัลให้ทันที)*

3. **ระบบคำนวณรางวัลข้างเคียงอัตโนมัติ (Auto-Adjacent Calculation)**:
   - เมื่อ Admin กรอกรางวัลที่ 1 เช่น `00051` และ `71827`
   - ระบบจะคำนวณและเติมรางวัลข้างเคียงให้ทันที 4 หมายเลข: `00050`, `00052`, `71826`, `71828`
   - แอดมินสามารถคลิกที่ช่องเพื่อแก้ไขหรือปรับแต่งหมายเลขได้อิสระ

4. **ระบบความปลอดภัยเฉพาะ Admin (Single Admin Role)**:
   - เข้าใช้งานผ่าน `/admin`
   - ป้องกันสิทธิ์ด้วยรหัสผ่านความปลอดภัย (ค่าเริ่มต้น: `admin2570`)
   - มีฟังก์ชันสลับสถานะ: "กำลังออกรางวัล (Live)", "ออกรางวัลเสร็จสิ้น", "พักการออกรางวัล"
   - มีปุ่ม "โหลดข้อมูลตัวอย่าง" และ "ล้างกระดาน" เพื่อเริ่มจับสลากจริง

5. **ระบบจัดเก็บข้อมูลบนคลาวด์ (MongoDB Atlas)**:
   - เชื่อมต่อกับ MongoDB Atlas ผ่าน Mongoose บนคอลเลกชัน `lotterystates`
   - มีระบบ Fallback บันทึกสำเนาลง Local JSON Storage (`data/lottery-state.json`) ควบคู่เสมอ

## 🚀 วิธีการรันโปรเจกต์

### 1. ติดตั้งแพ็กเกจ (Dependencies)
```bash
npm install
```

### 2. รันเซิร์ฟเวอร์
```bash
npm run dev
```

เปิดบราวเซอร์:
- **หน้าจอแสดงผลสด**: [http://localhost:3000](http://localhost:3000) (หรือพอร์ตที่เทอร์มินัลแจ้ง เช่น 3001)
- **หน้าจอจัดการแอดมิน**: [http://localhost:3000/admin](http://localhost:3000/admin) *(รหัสผ่าน: `admin2570`)*
